# Dossier v0.6.0

**Pre-release.** For local and development use only. Authentication and RLS are not yet in place ([ADR 0007](https://github.com/rwliebs/Dossier/blob/main/docs/adr/0007-release-gate-auth-rls-required.md)); production deployment is gated until those are complete.

---

## Upgrade

If you installed an earlier npm release (`0.5.x`), reinstall to get `0.6.0`:

```bash
npm i -g dossier-agentic-product-planner-builder@latest
dossier
```

**Or try without a global install:**

```bash
npx dossier-agentic-product-planner-builder@latest
```

**Or from source:**

```bash
git clone https://github.com/rwliebs/Dossier.git
cd Dossier
git checkout v0.6.0
pnpm install && pnpm run build && pnpm run dossier
```

Your browser will open to http://localhost:3000. On first run you'll be guided through API key setup, or go to `/setup`.

**Prerequisites:** Node.js 20+, [Anthropic API key](https://console.anthropic.com/). For GitHub (listing repos, HTTPS git, PR flow), use **Connect GitHub** on `/setup` after setting `GITHUB_OAUTH_CLIENT_ID` in `.env.local` (see [.env.example](../../.env.example)), or paste a [personal access token](https://github.com/settings/tokens) with `repo` scope. Agents can write files locally without GitHub.

## What's in this release

Highlights since `0.5.7`:

- **Planning chat continuity** — conversation history is sent with the planning prompt so follow-ups stay in context.
- **Repo default branch** — save and sync the connected repo's real default branch; builds start from that base.
- **CLI port handling** — if the preferred port is taken, Dossier picks a free port instead of crashing.
- **Planning timeouts** — activity resets the idle timeout; overall run limit still applies.
- **Build reliability** — single build lock, clearer Files labeling for the base branch, and related orchestration fixes.
- **Claude Max** — use your Claude Max account directly when Claude Code is installed locally (no extra API key setup required for that path).
- **Dependency and CI hardening** — Next.js, Electron Forge, SQLite native builds, and publish pipeline fixes so `npm publish` from the version tag is reliable.
